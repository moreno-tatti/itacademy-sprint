# ITAcademy Sprint

Repositorio dedicado a los ejercicios realizados durante la fase de especialización del programa IT Academy.

## 📚 Descripción

Este repositorio contiene las actividades, prácticas y ejercicios desarrollados a lo largo de los diferentes sprints de la especialización. El objetivo es recopilar y documentar el trabajo realizado, así como mostrar la evolución de los conocimientos adquiridos en las distintas áreas de estudio.

## 📁 Estructura del repositorio

Los ejercicios están organizados en carpetas independientes según el sprint, módulo o temática correspondiente.

## 🎯 Objetivo

Este repositorio tiene como finalidad:

- Centralizar todos los ejercicios realizados durante la formación.
- Mantener un registro organizado de los proyectos y prácticas.
- Facilitar la revisión y seguimiento del aprendizaje.
- Servir como portafolio técnico de los conocimientos adquiridos.
